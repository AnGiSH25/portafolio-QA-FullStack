_______________________________________________________________________
 Requisito original:
“El sistema debe ser rápido al cargar productos”

 Problema:
"Rápido" es ambiguo. ¿Cuánto tiempo es aceptable?

 Requisito corregido:
“El sistema debe mostrar la lista de productos en menos de 2 segundos en condiciones de red estándar”

 Criterio de prueba:
Simular carga de productos con red de 10 Mbps y verificar si la respuesta llega antes de 2 segundos.

_____________________________________________________________________
Requisito original:
"El usuario podrá registrarse fácilmente"

Problema:
"fácilmente"  es ambiguo. ¿Que datos específicos debe proporcionar el usuario?

Requisito corregido:
"El usuario podrá registrarse facílmente proporcionando los siguientes datos: nombre de usuario, correo electrónico, contraseña y año de nacimiento.

Criterio de prueba:
Simular el registro de un usuario sin proporcionar ciertos datos y verificar si el sistema permite que usuario se registre

_______________________________________________________________________
Requisito original:
"Los productos deben mostrarse con buena calidad de imagen."

Problema:
Que significa específicamente la expresión: "Buena calidad de imagen"

Requisito corregido:
las imágenes de cada producto debe mostrarse con una resolución de 8K o superior; para garantizar una buena calidad de imagen.

Criterio de prueba:
Cargar imágenes de con una resolución menor a 8K y verificar si el sistema las valida o no


_______________________________________________________________________
Requisito original:
"Si hay errores, el sistema debe avisar al usuario."

Problema:
"errores"  es ambiguo. ¿Que tipo de errores se deben reportar a el usuario?

Requisito corregido:
El sistema debe mostrar cuando los datos de login no sean validos y cuando haya fallos en algún proceso.




Criterio de prueba:
Intentar realizar el proceso de login con datos incorrectos y verificar si el sistema envia un mensaje claro y legible explicando el error.
_______________________________________________________________________

Requisito original:
"El sistema debe permitir pagar de diferentes formas."

Problema:
No se específica cuales son las formas de pago permitidas por el sistema.


Requisito corregido:
El sistema debe permitir que el usuario realice el pago utilizando, al menos, los siguientes métodos: tarjeta de crédito, tarjeta de débito, transferencia bancaria y billetera digital.




Criterio de prueba:
verificar si al seleccionar un método de pago se muestran específicamente los campos necesarios para completar la transacción y si además el sistema procesa y confirma el pago de manera segura antes de finalizar la compra.
